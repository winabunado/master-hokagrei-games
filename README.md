# Master HokaGrei PC & PS4 Games

Static catalogue starter for GitHub Pages.

## Deploy
1. Upload all files and folders in this ZIP to the root of `winabunado/master-hokagrei-games` on branch `main`.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions**.
4. The workflow in `.github/workflows/pages.yml` deploys on each push to `main`.
5. Check **Actions** for a green successful deployment.

Expected URL: https://winabunado.github.io/master-hokagrei-games/

## Catalogue data
`games.json` is a starter placeholder. Add reviewed game entries in this shape:
`{"name":"GAME TITLE","genre":["Action"],"size":20,"img":"https://...","lowEnd":false}`

Catalogue source reference: GamePrix0514/gamelist. Verify platform, compatibility, file sizes, artwork rights, and licensing before listing or selling any game.
